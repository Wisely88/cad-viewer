DWG 直接读取与自由引擎说明

本项目坚持100% 纯前端、零服务器上传、零授权费原则。


✨ 方式一：浏览器端 WebAssembly 直接秒开（推荐）

本系统已内置基于 Rust 编译的 dwgdxf (acadrust) WebAssembly 本地解析引擎。手机与电脑端均可直接点击“📂 打开图纸”选择 .dwg 文件，或直接拖拽进窗口，浏览器在内存中瞬间解码，全离线可用！


🛠 方式二：复杂专有图纸本地 CLI 深度解析（备用）

如遇到超出规范的复杂专有 3D 实体或版本高于 R2018 的图纸，可使用 GNU LibreDWG 进行深度转码：

brew install libredwg
./scripts/dwg-convert.sh sample.dwg
